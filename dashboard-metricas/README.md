# Dashboard de métricas de redes sociales

Página que arma un reporte de métricas de Instagram, TikTok, LinkedIn y YouTube.

## Cómo se usa

1. Abre `index.html` en el navegador.
2. Pega tu API key de Anthropic (se guarda solo en tu navegador).
3. Sube el PDF con tus métricas y dale a **Analizar con Claude**: llena las tarjetas y gráficas.
4. Usa **Descargar PDF** para exportar el reporte.
